train ¶

Run Push-T imitation training, checkpoint selection, and final evaluation.

Run lifecycle

  1. Parse TrainConfig, load demonstrations, and split whole episodes into training and validation subsets.
  2. Initialize a policy and training-only normalization, or load both from a checkpoint. Always start a fresh optimizer and training-step counter.
  3. Train while reporting metrics, validating, and evaluating rollout scores. Retain checkpoints and optionally stop when improvement plateaus.
  4. Reload the highest-scoring currently tracked checkpoint and evaluate it with separate final-evaluation streams and budget.

run_training owns the experiment directory, logging contexts, and temporary checkpoint lifetime. This is a training driver, not an optimizer/RNG-state resume mechanism.

LOG_ROOT = 'exp'

@dataclass(frozen=True, slots=True)
class TrainConfig:
    """Configure a Push-T imitation-learning training run.

    Architecture settings apply only to fresh policies. Training settings also
    apply when initializing from a checkpoint; loading does not resume the
    optimizer or the training-step counter.

    Attributes:
        init_from: Checkpoint used to initialize the policy and normalizer. A loaded
            policy supplies its architecture; optimizer state and training step start
            fresh.
        policy_type: Policy family for a fresh model: mean-squared-error imitation or
            flow matching. Ignored when loading a checkpoint.
        hidden_dims: Hidden-layer widths for a fresh policy. Ignored when loading a
            checkpoint.
        chunk_size: Number of actions predicted per observation by a fresh policy.
            Loaded policies retain their own prediction horizon.
        data_dir: Root directory used to find, download, and extract the Push-T dataset.
        pad_action_chunk_with_last_action: Pad incomplete action chunks with the
            episode’s final action when preparing training and validation samples.
        num_epochs: Maximum number of training epochs. Plateau stopping can end the run
            earlier.
        batch_size: Batch size for training and validation. Training drops the final
            incomplete batch; validation retains it.
        lr: Learning rate passed to the fresh AdamW optimizer.
        weight_decay: Weight-decay coefficient passed to AdamW.
        dropout_p: Override the policy’s dropout probability. None preserves loaded
            dropout settings; a fresh policy uses zero dropout.
        validation_interval: Optimizer steps between complete validation-loss passes.
            Validation also runs on the last scheduled training step.
        eval_interval: Optimizer steps between rollout evaluations used for checkpoint
            selection and plateau stopping. Selection evaluation also runs on the last
            scheduled training step.
        eval_episodes: Number of environment episodes in each checkpoint-selection
            evaluation.
        final_eval_episodes: Number of episodes in the separate final evaluation of the
            best retained checkpoint.
        early_stopping_patience: Consecutive selection evaluations without sufficient
            rollout-reward improvement before stopping, after warm-up. None disables
            plateau stopping.
        early_stopping_min_epochs: Warm-up duration converted to optimizer steps using
            the training-loader length. Stale evaluations count only after that step
            threshold.
        early_stopping_min_delta: Rollout-reward gain that must be strictly exceeded to
            reset patience. Small gains can accumulate against the last reference reward.
        save_checkpoints: Keep checkpoints in the experiment directory. If false,
            checkpoints are still written to a temporary directory, removed after
            success and retained after failure; W&B uploads are controlled separately.
        checkpoint_top_k: Number of best rollout-scored checkpoints retained in addition
            to the latest checkpoint. Zero retains only the latest.
        flow_num_steps: Integration steps for flow-policy rollout sampling, also
            recorded with checkpoints. Ignored by MSE policies.
        num_video_episodes: Maximum episodes recorded per selection or final evaluation.
            Zero disables video recording.
        video_size: Video frame dimensions as width and height. Both must be positive
            and even when recording is enabled.
        seed: Nonnegative root seed defining the experiment’s random-stream family. Keep
            it fixed when varying individual streams.
        data_split_variation: Realization of the stream that selects the fixed training
            and validation episode split.
        model_init_variation: Realization of the parameter-initialization stream for a
            fresh policy. Not used for loaded weights.
        train_loader_variation: Realization of the training-loader generator, which
            advances across epoch shuffles.
        train_loss_variation: Realization of the training-loss generator, including
            stochastic loss sampling and active dropout.
        validation_loader_variation: Realization of the validation-loader generator.
            Validation sample order remains fixed.
        validation_loss_variation: Realization of the loss generator restarted for each
            validation pass to use matching random draws.
        eval_env_variation: Realization of environment randomness for
            checkpoint-selection rollouts.
        eval_policy_variation: Realization of policy-sampling randomness for
            checkpoint-selection rollouts.
        final_eval_env_variation: Realization of the separate final-evaluation
            environment stream.
        final_eval_policy_variation: Realization of the separate final-evaluation
            policy-sampling stream.
        log_csv: Write training, validation, selection-evaluation, and final-evaluation
            CSV metrics.
        log_wandb: Initialize W&B and upload metrics, videos, and checkpoint artifacts.
            False disables W&B integration.
        log_interval: Optimizer steps between training-metric reports. Metrics are also
            reported on the last scheduled training step.
        wandb_project: W&B project used when W&B logging is enabled.
        exp_name: Optional suffix appended to the automatically generated experiment name
            containing the seed and timestamp.
        show_summary: Print effective configuration and dataset/model information before
            training.
    """

    # Policy initialization.
    # A loaded policy supplies its own architecture and normalizer.
    init_from: Path | None = None

    # Model architecture — used only when init_from is None.
    policy_type: PolicyType = "mse"
    hidden_dims: tuple[int, ...] = (256, 256, 256)
    chunk_size: int = 8

    # Dataset and sample preparation.
    data_dir: Path = Path("data")
    pad_action_chunk_with_last_action: bool = True

    # Training — applies to both fresh and loaded policies.
    num_epochs: int = 400
    batch_size: int = 128
    lr: float = 3e-4
    weight_decay: float = 0.0
    # None inherits loaded dropout; fresh models use zero.
    dropout_p: float | None = None

    # Validation and rollout evaluation, measured in training steps.
    validation_interval: int = 100
    eval_interval: int = 10_000
    eval_episodes: int = 100
    final_eval_episodes: int = 100

    # None disables plateau stopping. Warm-up does not count toward patience.
    early_stopping_patience: int | None = None
    early_stopping_min_epochs: int = 100
    early_stopping_min_delta: float = 0.005

    # Retain the best K rollout checkpoints, plus latest (0 = latest only).
    save_checkpoints: bool = True
    checkpoint_top_k: int = 3

    # Rollout inference and video recording.
    # flow_num_steps is ignored by MSE policies.
    flow_num_steps: int = 10
    num_video_episodes: int = 5
    video_size: tuple[int, int] = (256, 256)

    # Root seed identifies the experiment family.
    # Keep it fixed when varying individual sources of randomness.
    seed: int = 42

    # Independently selectable realizations of each stream.
    data_split_variation: int = 0
    model_init_variation: int = 0
    train_loader_variation: int = 0
    train_loss_variation: int = 0
    validation_loader_variation: int = 0
    validation_loss_variation: int = 0
    eval_env_variation: int = 0
    eval_policy_variation: int = 0
    final_eval_env_variation: int = 0
    final_eval_policy_variation: int = 0

    # Training metrics and experiment tracking.
    log_csv: bool = True
    log_wandb: bool = True
    log_interval: int = 100
    wandb_project: str = "cs285-hw1-imitation-learning"
    exp_name: str | None = None

    # Print the effective configuration and dataset/model facts before training.
    show_summary: bool = True

    def __post_init__(self) -> None:
        """Check supported configuration bounds when the dataclass is created.

        - Counts and intervals: num_epochs, batch_size, chunk_size, log_interval,
          validation_interval, eval_interval, eval_episodes, final_eval_episodes,
          and flow_num_steps must be positive.
        - Plateau stopping: if set, early_stopping_patience must be positive.
          early_stopping_min_epochs must be nonnegative; early_stopping_min_delta
          must be finite and nonnegative.
        - Dropout: if set, dropout_p must be in [0, 1).
        - Checkpoints and video: checkpoint_top_k and num_video_episodes must be
          nonnegative. With recording enabled, both video dimensions must be
          positive and even.
        - Randomness: the root seed must be a nonnegative integer. Training,
          validation, and selection stream variations must be integers in
          [0, 2**32). Booleans are rejected. Final-evaluation variations are
          validated when their streams are used, rather than here.

        Raises:
            TypeError: The root seed or a checked stream variation is not a
                Python integer (booleans are rejected).
            ValueError: A checked value lies outside its supported bounds.
        """
        for name in (
            "num_epochs",
            "batch_size",
            "chunk_size",
            "log_interval",
            "validation_interval",
            "eval_interval",
            "eval_episodes",
            "final_eval_episodes",
            "flow_num_steps",
        ):
            if getattr(self, name) <= 0:
                raise ValueError(f"{name} must be positive")

        streams = RandomStreamFactory(root_seed=self.seed)
        for stream, variation in (
            (StreamId.DATA_SPLIT, self.data_split_variation),
            (StreamId.MODEL_INIT, self.model_init_variation),
            (StreamId.TRAIN_LOADER, self.train_loader_variation),
            (StreamId.TRAIN_LOSS, self.train_loss_variation),
            (StreamId.VALIDATION_LOADER, self.validation_loader_variation),
            (StreamId.VALIDATION_LOSS, self.validation_loss_variation),
            (StreamId.EVAL_ENV, self.eval_env_variation),
            (StreamId.EVAL_POLICY, self.eval_policy_variation),
        ):
            streams.validate(stream, variation=variation)

        if (
            self.early_stopping_patience is not None
            and self.early_stopping_patience <= 0
        ):
            raise ValueError("early_stopping_patience must be positive")
        if self.early_stopping_min_epochs < 0:
            raise ValueError("early_stopping_min_epochs must be nonnegative")
        if (
            not math.isfinite(self.early_stopping_min_delta)
            or self.early_stopping_min_delta < 0
        ):
            raise ValueError("early_stopping_min_delta must be finite and nonnegative")

        if self.dropout_p is not None and not 0.0 <= self.dropout_p < 1.0:
            raise ValueError("dropout_p must be in [0, 1)")

        if self.checkpoint_top_k < 0:
            raise ValueError("checkpoint_top_k must be nonnegative")

        if self.num_video_episodes < 0:
            raise ValueError("num_video_episodes must be nonnegative")

        if self.num_video_episodes > 0:
            width, height = self.video_size
            if width <= 0 or height <= 0 or width % 2 or height % 2:
                raise ValueError("Video dimensions must be positive and even")

        (StreamId.EVAL_POLICY, self.eval_policy_variation),
    ):
        streams.validate(stream, variation=variation)

    if (
        self.early_stopping_patience is not None
        and self.early_stopping_patience <= 0
    ):
        raise ValueError("early_stopping_patience must be positive")
    if self.early_stopping_min_epochs < 0:
        raise ValueError("early_stopping_min_epochs must be nonnegative")
    if (
        not math.isfinite(self.early_stopping_min_delta)
        or self.early_stopping_min_delta < 0
    ):
        raise ValueError("early_stopping_min_delta must be finite and nonnegative")

    if self.dropout_p is not None and not 0.0 <= self.dropout_p < 1.0:
        raise ValueError("dropout_p must be in [0, 1)")

    if self.checkpoint_top_k < 0:
        raise ValueError("checkpoint_top_k must be nonnegative")

    if self.num_video_episodes < 0:
        raise ValueError("num_video_episodes must be nonnegative")

        if width <= 0 or height <= 0 or width % 2 or height % 2:
            raise ValueError("Video dimensions must be positive and even")

    - Validation preserves sample order and retains the final incomplete batch.

      fixed validation order does not imply its generator is never consumed.

      generator across epochs to advance shuffles; recreate it to replay a run
      with unchanged data and loader settings.

        config: Batch-size and action-padding settings. Architecture is supplied
            separately through `chunk_size` and the prepared data.
        train_episodes: Fixed training subset of whole episodes.
        validation_episodes: Fixed validation subset of whole episodes.
        normalizer: Shared statistics applied when constructing both window datasets.
        chunk_size: Action-window length, normally the actual policy horizon.

        validation_generator: CPU generator retained by the unshuffled validation loader.

            or PyTorch rejects loader settings.
        TypeError: A child rejects a non-integer or boolean chunk size.

    A valid window dataset can still yield zero training batches when every sample
    falls in the dropped remainder; `run_training` checks this separately.
    """

        episodes=train_episodes,
        chunk_length=chunk_size,
        normalizer=normalizer,
        pad_action_chunk=config.pad_action_chunk_with_last_action,
    )
    validation_dataset = EpisodeChunkDataset(
        episodes=validation_episodes,
        chunk_length=chunk_size,
        normalizer=normalizer,
        pad_action_chunk=config.pad_action_chunk_with_last_action,
    )

    train_loader = DataLoader(
        dataset=train_dataset,
        batch_size=config.batch_size,
        shuffle=True,
        drop_last=True,
        num_workers=0,
        generator=train_generator,
    )
    validation_loader = DataLoader(
        dataset=validation_dataset,
        batch_size=config.batch_size,
        shuffle=False,
        drop_last=False,
        num_workers=0,
        generator=validation_generator,
    )

    return train_loader, validation_loader

  • Use an available Torch accelerator, otherwise CPU. Download/load Push-T data and split whole episodes approximately 80/20 using the data-split stream.

def run_training(config: TrainConfig) -> None:
    """Execute one fresh training run and write its experiment outputs.

    **Data and initialization**

    - Use an available Torch accelerator, otherwise CPU. Download/load Push-T data
      and split whole episodes approximately 80/20 using the data-split stream.
    - For a fresh policy, fit normalization only on training episodes and initialize
      weights with the model-init stream. When loading a checkpoint, reuse its
      architecture and normalization; optionally override dropout.
    - Build window loaders using the actual model horizon. Start a new AdamW
      optimizer and step counter even when weights came from a checkpoint.

    **Reporting and selection**

    - Report training-window means, validation loss, and selection rollouts at their
      configured intervals and the last scheduled training step.
    - Reuse training loss/loader generators across batches and epochs. Restart the
      validation-loss generator for every complete validation pass. Selection
      rollouts recreate indexed episode streams; final rollouts use separate streams.
    - Save after each selection evaluation, retaining best K plus latest. Optional
      plateau stopping counts eligible selection evaluations, with warm-up converted
      from epochs to optimizer steps.
    - On scheduled completion or plateau, reload the best currently tracked record
      by `(score, step)` and run final evaluation. With latest-only retention this
      normally selects the latest, not the best checkpoint from the full history.
      Failed-cleanup records remain tracked and can refer to missing local files;
      loading such a selected record propagates the failure.
    - Flush any remaining training-metric window after leaving the loops. Plateau
      stopping does not force an additional off-schedule validation pass.

    **Output ownership**

    Create a new `exp/seed_<seed>_<timestamp>[_suffix]` directory relative to the
    working directory. Own the W&B and progress contexts; reject offline W&B runs.
    Disable W&B explicitly for local-only training. CSV settings do not disable
    checkpoint creation or the experiment directory. Final-evaluation videos
    remain local; the final metric call does not submit their paths to W&B.

    Persistent checkpoints stay under the experiment directory. When disabled,
    use temporary checkpoints for selection/final evaluation and remove them only
    on successful context exit. Failures propagate, close registered contexts, and
    may leave partial experiment outputs or temporary checkpoints for inspection.
    There is no transactional rollback or resumable optimizer/RNG-state snapshot.

    Args:
        config: Validated training settings. Loaded architecture overrides fresh-model
            options; current training, logging, and evaluation settings still apply.

    Raises:
        ValueError: No complete training batches remain, W&B is offline, or a
            delegated configuration/data/policy validation fails.
        FileExistsError: The generated experiment directory or a required fresh
            output destination already exists.

    Dataset, device, filesystem, W&B, and encoding errors propagate. The function
    returns no trained model; retained checkpoints and reports are its outputs.
    """
    streams = RandomStreamFactory(root_seed=config.seed)

    device = torch.accelerator.current_accelerator()
    if device is None or not torch.accelerator.is_available():
        device = torch.device("cpu")

    zarr_path = download_pusht(config.data_dir)
    episodes_dataset = load_episodes_dataset(zarr_path=zarr_path)

    # We are not splitting out a test because policy performance is
    # evaluated through environment rollouts using separately controlled
    # evaluation randomness.
    train_episodes_subset, validation_episodes_subset = random_split(
        dataset=episodes_dataset,
        lengths=[0.8, 0.2],
        generator=streams.torch(
            StreamId.DATA_SPLIT,
            variation=config.data_split_variation,
        ),
    )

    if config.init_from is None:
        normalizer = Normalizer.from_episodes_data(episodes=train_episodes_subset)

        model = build_policy(
            PolicyConfig(
                policy_type=config.policy_type,
                state_dim=normalizer.state_dim,
                action_dim=normalizer.action_dim,
                chunk_size=config.chunk_size,
                hidden_dims=config.hidden_dims,
            ),
            cpu_generator=streams.torch(
                StreamId.MODEL_INIT,
                variation=config.model_init_variation,
                device="cpu",
            ),
            target_device=device,
        )

    else:
        model, normalizer, _ = load_policy(
            path=config.init_from,
            device=device,
        )

    if config.dropout_p is not None:
        override_dropout_p(model, config.dropout_p)
    device = next(model.parameters()).device

    # Create fresh for each training run; advance across its batches and epochs.
    # Streams with matching identities on the same backend reproduce the starting RNG state.
    train_loss_generator = streams.torch(
        StreamId.TRAIN_LOSS,
        variation=config.train_loss_variation,
        device=device,
    )

    train_loader, validation_loader = build_loaders(
        config=config,
        train_episodes=train_episodes_subset,
        validation_episodes=validation_episodes_subset,
        normalizer=normalizer,
        chunk_size=model.chunk_size,
        train_generator=streams.torch(
            StreamId.TRAIN_LOADER,
            variation=config.train_loader_variation,
        ),
        validation_generator=streams.torch(
            StreamId.VALIDATION_LOADER,
            variation=config.validation_loader_variation,
        ),
    )

    if len(train_loader) == 0:
        raise ValueError("No training batches; reduce batch_size or check the dataset.")

    optimizer = torch.optim.AdamW(
        params=model.parameters(),
        lr=config.lr,
        weight_decay=config.weight_decay,
    )
    global_step = 0

    # Setup logging
    exp_name = f"seed_{config.seed}_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
    if config.exp_name is not None:
        exp_name += f"_{config.exp_name}"

    # The training driver owns the directory and all output lifetimes.
    log_dir = Path(LOG_ROOT) / exp_name
    log_dir.mkdir(parents=True, exist_ok=False)

    total_steps = config.num_epochs * len(train_loader)
    stopper = (
        EarlyStopping(
            patience=config.early_stopping_patience,
            min_delta=config.early_stopping_min_delta,
            start_step=config.early_stopping_min_epochs * len(train_loader),
            objective="max",
        )
        if config.early_stopping_patience is not None
        else None
    )
    stop_requested = False
    stop_reason = "max_epochs"
    loss_sum = 0.0
    window_examples_count = 0

    display_metrics = {
        "epoch": f"1/{config.num_epochs}",
        "loss": "—",
        "val": "—",
        "eval": "—",
    }

    wandb_run_config = config_to_dict(config)
    wandb_run_config["model_config"] = asdict(model.config)
    wandb_run_config["training_config"] = {"dropout": get_dropout_config(model)}

    with ExitStack() as stack:
        # Checkpoint Directory management.
        # Auto clears temp dirs on successful completion only.
        checkpoint_dir = (
            log_dir / "checkpoints"
            if config.save_checkpoints
            else stack.enter_context(temp_checkpoint_dir(exp_name=exp_name))
        )

        run = (
            stack.enter_context(
                wandb.init(
                    project=config.wandb_project,
                    config=wandb_run_config,
                    name=exp_name,
                    dir=str(log_dir),
                )
            )
            if config.log_wandb
            else None
        )

        if run is not None and run.offline:
            raise ValueError(
                "Offline W&B is not supported by this training driver. "
                "Use --log-wandb False for local-only runs."
            )

        logger = ExperimentLogger(log_dir, run=run, log_csv=config.log_csv)
        checkpoints: dict[int, CheckpointRecord] = {}
        pending_cleanup: set[int] = set()

        if config.show_summary:
            model_device = next(model.parameters()).device
            device_label = str(model_device)
            if model_device.type == "cuda":
                device_label += f" · {torch.cuda.get_device_name(model_device)}"
            Console(stderr=True).print(
                build_training_summary(
                    config=config,
                    model=model,
                    run_name=exp_name,
                    device=device_label,
                    output_dir=log_dir,
                    dataset_path=zarr_path,
                    train_episodes=len(train_episodes_subset),
                    validation_episodes=len(validation_episodes_subset),
                    train_samples=len(
                        cast(Sequence, train_loader.dataset)
                    ),  # can be safely cast here since dataset does have len.
                    validation_samples=len(
                        cast(Sequence, validation_loader.dataset)
                    ),  # can be safely cast here since dataset does have len.
                    steps_per_epoch=len(train_loader),
                )
            )

        progress = stack.enter_context(
            tqdm(
                total=total_steps,
                desc="Train",
                unit="step",
                position=0,
                leave=True,
                dynamic_ncols=True,
                mininterval=0.5,
                miniters=1,
                disable=None,
                postfix=display_metrics,
            )
        )

        epoch = 0
        for epoch in range(config.num_epochs):
            display_metrics["epoch"] = f"{epoch + 1}/{config.num_epochs}"
            progress.set_postfix(display_metrics, refresh=False)
            for state, action_chunk in train_loader:
                loss = train_step(
                    model=model,
                    optimizer=optimizer,
                    state=state.to(device),
                    action_chunk=action_chunk.to(device),
                    generator=train_loss_generator,
                )
                global_step += 1

                # compute_loss() returns a batch mean. Weight it by the
                # number of examples before combining it with other batches.

                batch_examples = state.shape[0]
                loss_sum += loss.item() * batch_examples
                window_examples_count += batch_examples

                training_complete = global_step == total_steps
                eval_due = global_step % config.eval_interval == 0 or training_complete
                log_due = global_step % config.log_interval == 0 or training_complete
                validation_due = (
                    global_step % config.validation_interval == 0 or training_complete
                )

                if log_due:
                    mean_loss = loss_sum / window_examples_count

                    logger.log_train(
                        global_step=global_step,
                        epoch=epoch,
                        loss_window_mean=mean_loss,
                        window_examples_count=window_examples_count,
                    )

                    display_metrics["loss"] = f"{mean_loss:.4g}"
                    progress.set_postfix(display_metrics, refresh=False)

                    loss_sum = 0.0
                    window_examples_count = 0

                # Advance after the optimizer step; tqdm throttles redraws.
                progress.update(1)

                if validation_due:
                    # Restart validation RNG for each complete pass so checkpoints use
                    # matching draws, assuming unchanged batch order and sampling shapes.
                    validation_result = compute_validation_loss(
                        model=model,
                        loader=validation_loader,
                        device=device,
                        generator=streams.torch(
                            StreamId.VALIDATION_LOSS,
                            variation=config.validation_loss_variation,
                            device=device,
                        ),
                    )
                    logger.log_validation(
                        global_step=global_step,
                        loss_mean=validation_result.loss_mean,
                        examples_count=validation_result.examples_count,
                    )

                    display_metrics["val"] = f"{validation_result.loss_mean:.4g}"
                    progress.set_postfix(display_metrics, refresh=False)

                if eval_due:
                    progress.set_description_str("Evaluating")
                    video_dir = None
                    if config.num_video_episodes > 0:
                        video_dir = log_dir / "videos" / f"step_{global_step:08d}"
                        video_dir.mkdir(parents=True, exist_ok=False)

                    result = evaluate_policy(
                        model=model,
                        normalizer=normalizer,
                        device=device,
                        chunk_size=model.chunk_size,
                        video_size=config.video_size,
                        num_video_episodes=config.num_video_episodes,
                        num_eval_episodes=config.eval_episodes,
                        flow_num_steps=config.flow_num_steps,
                        streams=streams,
                        env_stream=StreamId.EVAL_ENV,
                        policy_stream=StreamId.EVAL_POLICY,
                        env_variation=config.eval_env_variation,
                        policy_variation=config.eval_policy_variation,
                        video_dir=video_dir,
                        show_progress=not progress.disable,
                        progress_position=1,
                    )

                    logger.log_eval(
                        global_step=global_step,
                        mean_reward=result.mean_reward,
                        num_episodes=result.num_episodes,
                        video_paths=result.video_paths,
                    )

                    display_metrics["eval"] = f"{result.mean_reward:.3f}@{global_step}"
                    progress.set_postfix(display_metrics, refresh=False)

                    progress.set_description_str("Saving")

                    pending_cleanup = save_checkpoint_and_retain(
                        model=model,
                        step=global_step,
                        checkpoint_dir=checkpoint_dir,
                        run=run,
                        mean_reward=result.mean_reward,
                        top_k=config.checkpoint_top_k,
                        checkpoints=checkpoints,
                        normalizer=normalizer,
                        flow_num_steps=config.flow_num_steps,
                    )

                    if stopper is not None and not training_complete:
                        stop_requested = stopper.update(
                            step=global_step,
                            value=result.mean_reward,
                        )
                        if stop_requested:
                            stop_reason = "plateau"
                    progress.set_description_str("Train")

                final_eval_due = training_complete or stop_requested

                if final_eval_due:
                    progress.set_description_str("Running Final Evaluation")

                    # Retrieve best model / weights.
                    # NOTE: we tie break to last step; [nit] double descent.
                    best_step = max(
                        checkpoints, key=lambda step: (checkpoints[step].score, step)
                    )
                    best_model_record = checkpoints[best_step]
                    best_model, best_normalizer, inference = load_policy(
                        path=best_model_record.path, device=device
                    )

                    video_dir = None
                    if config.num_video_episodes > 0:
                        # TODO: confirm that the best_step here is in the same scale as global_step; not epochs.
                        video_dir = log_dir / "videos" / f"best_step_{best_step:08d}"
                        video_dir.mkdir(parents=True, exist_ok=False)

                    # call final evaluation using evaluate_policy()
                    final_eval_result = evaluate_policy(
                        model=best_model,
                        normalizer=best_normalizer,
                        device=device,
                        chunk_size=best_model.chunk_size,
                        video_size=config.video_size,
                        num_video_episodes=config.num_video_episodes,
                        num_eval_episodes=config.final_eval_episodes,
                        flow_num_steps=inference["flow_num_steps"],
                        streams=streams,
                        env_stream=StreamId.FINAL_EVAL_ENV,
                        policy_stream=StreamId.FINAL_EVAL_POLICY,
                        env_variation=config.final_eval_env_variation,
                        policy_variation=config.final_eval_policy_variation,
                        video_dir=video_dir,
                        show_progress=not progress.disable,
                        progress_position=1,
                    )

                    logger.log_final_evaluation(
                        global_step=global_step,
                        mean_reward=final_eval_result.mean_reward,
                        num_episodes=final_eval_result.num_episodes,
                        checkpoint_step=best_step,
                        selection_mean_reward=best_model_record.score,
                        stop_reason=stop_reason,
                    )

                if stop_requested:
                    break
            if stop_requested:
                break

        if window_examples_count:
            logger.log_train(
                global_step=global_step,
                epoch=epoch,
                loss_window_mean=loss_sum / window_examples_count,
                window_examples_count=window_examples_count,
            )
        progress.set_description_str("Stopped (plateau)" if stop_requested else "Done")

        logging.info("Training ended at step %s: %s", global_step, stop_reason)
        if run is not None:
            run.summary["stop_reason"] = stop_reason

        if pending_cleanup:
            logging.warning(
                "Training finished with checkpoint cleanup pending for steps %s. "
                "Extra local files or W&B artifacts may remain.",
                sorted(pending_cleanup),
            )
